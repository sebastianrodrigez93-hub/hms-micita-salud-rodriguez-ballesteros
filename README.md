# Plataforma MiCita Salud - Modelado Funcional

## Descripción del Proyecto
Modelado de requisitos funcionales mediante diagramas de casos de uso (UML 2.5) para la plataforma "MiCita Salud", un sistema de gestión de agendas médicas para una IPS.

## Herramienta Utilizada
StarUML (UML 2.5). El archivo fuente del modelo se encuentra adjunto en la raíz de este repositorio con extensión .mdj.
